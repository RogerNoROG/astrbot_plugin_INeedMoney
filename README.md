# 给我打钱！

AstrBot 插件。默认定时检查 DeepSeek API 余额，也支持高级用户接入自定义余额接口；余额不足时，仅向配置的群聊或私聊主动发送充值提醒，并可附带收款码。

## 安装要求

- AstrBot `>=4.13,<5`
- 目标消息平台需要支持 AstrBot 的主动消息发送。QQ 官方机器人不支持该能力。
- 默认支持 DeepSeek；也可接入返回 JSON 的自定义余额接口。

安装插件后，请在 AstrBot WebUI 安装 `requirements.txt` 中的依赖，并重载插件。

## 配置步骤

1. 在插件配置中选择 `DeepSeek` 并填写 DeepSeek API Key。只粘贴 `sk-...` 形式的密钥，不要加 `Bearer`。
2. 设置余额提醒模板、余额恢复感谢模板和告警 AI 温度；插件会读取目标对话历史，使用当前 AstrBot Persona 调用模型，并将生成的告警回复写回当前 AstrBot 对话。
3. 设置低余额告警阈值、轮询间隔和重复提醒间隔。DeepSeek 的余额单位为人民币（CNY）。
4. 在需要接收通知的群聊或私聊中，用 AstrBot 管理员账号发送 `/余额监控会话`，将返回的会话标识逐项填入“允许接收提醒的会话列表”。只有列表中的会话会收到主动推送。
5. 按需上传收款码图片，可上传多张（例如多个平台的收款码），会按上传顺序全部附带；然后启用余额监控。
6. 在任意会话中用管理员账号发送 `/余额查询`，验证 API Key 是否可用。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/余额查询` | 立即查询余额并返回结果，同时验证接口配置。 |
| `/余额告警测试` | 使用示例低余额在当前会话发送告警样式和收款码，不请求真实余额。 |
| `/余额恢复测试` | 使用示例高余额在当前会话发送余额恢复感谢消息，不请求真实余额。 |
| `/余额监控会话` | 返回当前会话的 `unified_msg_origin`，用于配置通知白名单。 |
| `/余额监控会话添加` | 将当前群聊或私聊自动加入余额提醒会话列表，无需手动填写会话 ID。 |
| `/余额监控状态` | 查看后台最近一次检查结果，不额外请求余额 API。 |

以上命令均仅限 AstrBot 管理员使用。

## DeepSeek 接口

插件固定使用 DeepSeek 官方余额接口 `https://api.deepseek.com/user/balance`，自动附加认证请求头并读取人民币（CNY）余额。配置页不会显示接口地址、请求头或返回字段等技术参数。

## 自定义接口

只有需要对接其他服务商时，才在“AI 平台”选择“自定义接口”，再展开“高级：自定义余额接口”表单。DeepSeek 用户不需要填写这一部分。

需要提供：余额 API 地址、请求方式、认证信息，以及响应中“剩余余额”的 JSON 路径。若接口响应为：

```json
{
  "data": {
    "remaining": 12.5
  }
}
```

则“余额 JSON 路径”填写 `data.remaining`。路径支持数组索引，例如 `data.accounts[0].balance`。令牌字段填写完整的请求头值，例如 `Bearer sk-...`；如服务商使用其他认证方式，可在“额外请求头 JSON”中填写。记得将“余额单位”与服务商的实际币种保持一致。

## 行为说明

- 查询失败只写入 AstrBot 插件日志，不发送“余额不足”提醒，避免网络故障导致误报。
- 告警文案由目标对话当前 Persona 实时生成；模型调用失败或生成结果未保留余额、阈值、单位等事实时，自动回退到配置模板。
- 余额从低于阈值恢复到阈值以上时，每个监控会话只发送一次感谢消息；再次低于阈值并恢复后会再次发送。
- 余额恢复到阈值及以上后，下次再次低于阈值会立即提醒。
- 若所有会话发送失败，不会进入冷却期，会在下一轮继续尝试。
- WebUI 中的 API Key 和接口令牌会被遮罩显示，但 AstrBot 的 `secret` 配置不会加密磁盘中的值，请妥善保护部署目录与备份。
