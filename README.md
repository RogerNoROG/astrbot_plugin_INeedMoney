# 给我打钱！

AstrBot 插件。可同时监控多个 AI API 余额（DeepSeek、derouter 内置预设，以及自定义 JSON 接口）；余额不足时，仅向配置的群聊或私聊主动发送充值提醒，并可附带多张收款码。

## 安装要求

- AstrBot `>=4.13,<5`
- 目标消息平台需要支持 AstrBot 的主动消息发送。QQ 官方机器人不支持该能力。
- 内置支持 DeepSeek 与 derouter；也可接入返回 JSON 的自定义余额接口。

安装插件后，请在 AstrBot WebUI 安装 `requirements.txt` 中的依赖，并重载插件。

## 配置结构

所有平台配置都平铺在同一级，每个平台有独立开关，可任意组合同时启用：

| 平台 | 开关 | 主要配置项 |
| --- | --- | --- |
| DeepSeek | 启用 DeepSeek 余额监控 | DeepSeek API Key、DeepSeek 账户名称 |
| derouter | 启用 derouter 余额监控 | derouter 密钥、derouter 密钥类型、derouter API 地址、derouter 账户名称、derouter 余额单位 |
| 自定义接口 | 启用自定义接口余额监控 | 自定义接口账户名称、余额 API 地址、请求方法、令牌、请求头、余额 JSON 路径、换算系数、余额单位 |

`启用余额监控` 是总开关：关闭后不请求任何余额接口，也不发送提醒。

## 配置步骤

1. 打开需要监控的平台开关（可多选）：
   - `启用 DeepSeek 余额监控`：填写 DeepSeek API Key，只粘贴 `sk-...` 形式，不要加 `Bearer`。
   - `启用 derouter 余额监控`：填写 derouter 密钥，并选择密钥类型（账户密钥／客户密钥）。接口地址与余额字段已按官方文档预设。
   - `启用自定义接口余额监控`：仅在对接其他服务商时开启，需要自行填写接口地址与余额字段。
2. 设置余额提醒模板、余额恢复感谢模板和告警 AI 温度；插件会读取目标对话历史，使用当前 AstrBot Persona 调用模型，并将生成的告警回复写回当前 AstrBot 对话。
3. 设置低余额告警阈值、轮询间隔和重复提醒间隔。阈值对所有平台生效：DeepSeek 余额单位为人民币（CNY），derouter 为美元（USD），自定义接口由“余额单位”决定。
4. 在需要接收通知的群聊或私聊中，用 AstrBot 管理员账号发送 `/余额监控会话` 或 `/余额监控会话添加`，把会话加入“允许接收提醒的会话列表”。只有列表中的会话会收到主动推送。
5. 按需上传收款码图片，可上传多张（例如多个平台的收款码），会按上传顺序全部附带；然后打开 `启用余额监控`。
6. 在任意会话中用管理员账号发送 `/余额查询`，查看所有已启用平台的余额。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/余额查询` | 查询所有已启用平台的余额并分别返回结果，同时验证接口配置。 |
| `/余额告警测试` | 为每个已启用平台发送示例低余额告警样式和收款码，不请求真实余额。 |
| `/余额恢复测试` | 为每个已启用平台发送示例余额恢复感谢消息，不请求真实余额。 |
| `/余额监控会话` | 返回当前会话的 `unified_msg_origin`，用于配置通知白名单。 |
| `/余额监控会话添加` | 将当前群聊或私聊自动加入余额提醒会话列表，无需手动填写会话 ID。 |
| `/余额监控状态` | 查看每个已启用平台最近一次检查结果，不额外请求余额 API。 |

以上命令均仅限 AstrBot 管理员使用。两个测试命令在没有任何平台启用时，会依次展示全部平台的样式预览。

## DeepSeek 接口

插件固定使用 DeepSeek 官方余额接口 `https://api.deepseek.com/user/balance`，自动附加认证请求头并读取人民币（CNY）余额。配置页不会显示接口地址、请求头或返回字段等技术参数。

## derouter 接口

选择 `derouter` 后，插件按官方文档预设接口，只需填写密钥并选择密钥类型：

| 密钥类型 | 接口 | 读取字段 |
| --- | --- | --- |
| 账户密钥 | `GET /balance` | `available`（可用余额） |
| 客户密钥 | `GET /sub-key/balance` | `remaining`（剩余额度） |

默认地址为 `https://cf-api.derouter.ai`，使用反向代理时可在“API 地址”中修改。币种为美元（USD）。若接口返回 `401`，插件会提示检查密钥。

## 自定义接口

只有需要对接其他服务商时，才打开“启用自定义接口余额监控”，并填写同一级的自定义接口配置项。使用 DeepSeek 或 derouter 时无需填写这一部分。

需要提供：余额 API 地址、请求方式、认证信息，以及响应中“剩余余额”的 JSON 路径。若接口响应为：

```json
{
  "data": {
    "remaining": 12.5
  }
}
```

则“余额 JSON 路径”填写 `data.remaining`。路径支持数组索引，例如 `data.accounts[0].balance`。令牌字段填写完整的请求头值，例如 `Bearer sk-...`；如服务商使用其他认证方式，可在“额外请求头 JSON”中填写。记得将“余额单位”与服务商的实际币种保持一致。

## 行为说明

- 各平台独立判断余额状态：某一平台恢复或告警，不会影响其他平台。
- 查询失败只写入 AstrBot 插件日志，不发送“余额不足”提醒，避免网络故障导致误报。某个平台失败时会跳过该平台并继续检查其他平台。
- 告警文案由目标对话当前 Persona 实时生成；模型调用失败或生成结果未保留余额、阈值、单位等事实时，自动回退到配置模板。
- 余额从低于阈值恢复到阈值以上时，每个监控会话只发送一次感谢消息；再次低于阈值并恢复后会再次发送。
- 余额恢复到阈值及以上后，下次再次低于阈值会立即提醒。重复提醒间隔按平台分别计算。
- 若所有会话发送失败，不会进入冷却期，会在下一轮继续尝试。
- 从旧版本升级时，原来的单平台配置（DeepSeek／derouter／自定义接口）会在插件首次加载时自动迁移到新的多平台配置，并自动打开对应平台开关。
- WebUI 中的 API Key 和接口令牌会被遮罩显示，但 AstrBot 的 `secret` 配置不会加密磁盘中的值，请妥善保护部署目录与备份。
